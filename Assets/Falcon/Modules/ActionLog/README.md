# ActionLog
## Tổng quan
- **Tên:** `ActionLog`
- **Giới thiệu:** Log các hành vi của người dùng lên BigData

## Quick Start
- FActionLogManager.Log(action, param).Send(); //Gửi log lên bigdata, dữ liệu chậm mất vài tiếng
- new CSActionLog(action, param).Send(); //Gửi log lên server logic, dữ liệu realtime
