# Module PhoneUtil

## Tổng quan
- **Tên:** `Phone Util`
- **Giới thiệu:** Cung cấp các tiện ích liên quan đến điện thoại, bao gồm chụp ảnh màn hình hiện tại, v.v.
## Quick Start
- Server gửi bản tin `SCCaptureScreenshotReq` để yêu cầu Client chụp ảnh màn hình và gửi kết quả về Server qua bản tin `CSCaptureScreenshotRsp`.
